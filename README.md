# TrackX — Kochi Metro Smart Train Scheduler

AI-powered Kochi Metro train scheduling and employee fleet management system.

## Features

- AI-generated train schedules
- Day-wise schedules
- Train journey search
- Upcoming departures
- Train frequency
- Employee train control
- Available/unavailable train management
- Backup train replacement
- Station information
- FastAPI backend
- Web frontend

## Run Backend

pip install -r requirements.txt
python -m uvicorn backend_server:app --host 0.0.0.0 --port 8000

## Run Website

The website is inside the website folder.
